Мы решили отложить React component tests до первого рабочего деплоя.

Планируемые задачи:

- настроить React Testing Library
- настроить jsdom для Vitest
- добавить файл `src/test/setup.js`
- протестировать компонент `FieldError`
- протестировать auth-формы:
  - `LoginPage`
  - `RegisterPage`
- протестировать feedback-форму:
  - `FeedbackPage`
- протестировать форму места:
  - `PlaceForm`
- протестировать route guards:
  - `ProtectedRoute`
  - `GuestOnlyRoute`

Почему откладываем:

Utility tests уже дают пользу и не требуют сложной настройки.
Component tests требуют дополнительной конфигурации и их удобнее добавить после того, как деплой будет стабильно работать.
